# 🚀 Smart Reconciliation & Audit System

## 📌 Overview

The **Smart Reconciliation & Audit System** is a full-stack application designed to simulate enterprise-level financial transaction reconciliation used in banking, ERP, and accounting systems.

It enables users to:

- Upload transaction CSV files
- Automatically reconcile data
- Detect exact, partial, duplicate, and unmatched records
- View dashboard analytics
- Manually edit records
- Track immutable audit logs
- Enforce role-based access control

This project demonstrates clean architecture, async processing.
